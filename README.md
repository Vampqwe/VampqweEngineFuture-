# 🚀 VampqweEngineFuture

Модульный PHP 8+ движок с чистой архитектурой, DI-контейнером, системой самодиагностики (Doctor) и поддержкой различных БД.

## 📋 Особенности

- PHP 8.1+ (Enum, readonly, named arguments)
- 100% ООП с `declare(strict_types=1)`
- Модульная архитектура с полной инкапсуляцией
- DI-контейнер с автоматическим разрешением зависимостей
- Две дороги маршрутизации (системная и пользовательская)
- Система состояний (NotInstalled, Installing, Maintenance, Running, Error)
- **Модуль Doctor** — самодиагностика сборки
- Поддержка MySQL, PostgreSQL, SQLite
- Инсталятор для первого запуска
- Обработчик ошибок с красивыми страницами

## 📁 Структура
├── public/ ← точка входа
├── app/ ← пользовательское приложение
├── core/
│ ├── system/ ← ядро (App, Kernel, Container, Router)
│ └── module/ ← модули движка (Config, Database, Doctor, ...)
├── config/ ← главные конфиги
├── routes/ ← системные маршруты
├── view/ ← шаблоны
├── assets/ ← статика
├── storage/ ← данные (logs, cache, sessions)
├── migrations/ ← миграции БД
├── tests/ ← тесты
└── bin/ ← CLI-команды

## 🩺 Модуль Doctor

Самодиагностика сборки: проверяет наличие и работоспособность всех модулей ядра, выдаёт понятный вердикт.

- Если всё ок — сайт работает
- Если критичный модуль сломан — страница 503 с диагнозом
- CLI: `php bin/engine doctor`
- HTTP: `/system/health`
